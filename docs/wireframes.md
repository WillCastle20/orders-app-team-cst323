# Users Feature Wireframes

## login.html
- Title: Login
- Username input
- Password input
- Login button
- Registration link
- Error and success message area

## register.html
- Title: Register
- Username input
- Password input
- Confirm password input
- Register button
- Login link
- Validation and error message area

## userAdmin.html
- Title: User Administration
- Table displaying users
- Columns: Username, Role, Enabled
- Edit button for each user
- Delete button for each user
- Feedback message area

## editUser.html
- Title: Edit User
- Username input
- Role selection
- Enabled checkbox
- Save Changes button
- Cancel button
- Validation and error message area

## confirmDeleteUser.html
- Title: Confirm Delete User
- Display selected username
- Warning message
- Confirm Delete button
- Cancel button
- Success or error message area
